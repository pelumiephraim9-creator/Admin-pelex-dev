PELEX DESKTOP (Windows)

Build it on your own computer (free):
1. Install Node.js LTS from nodejs.org.
2. Open this folder in a terminal and run:  npm install
3. Run:  npm run dist
4. The installer appears in the "dist" folder (Pelex Setup x.y.z.exe).

Note: Windows SmartScreen will show "Windows protected your PC" the first time.
Click "More info", then "Run anyway". Removing that warning requires a code-signing
certificate, which costs about $200 to $700 a year.

To run without installing: npm start
Before building, add a 256x256 icon file named icon.ico in this folder (optional).
